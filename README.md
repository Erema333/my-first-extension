# My First Extension — Генератор случайных чисел (Random Number Generator)

Плагин для среды разработки **Visual Studio Code**, предоставляющий встроенное интерактивное окно (Webview) для быстрой генерации случайных целых чисел в заданном пользователем диапазоне.

## Описание и функциональные возможности

Расширение (`my-first-extension`) интегрируется в командную палитру VS Code и позволяет открывать отдельную вкладку с графическим интерфейсом для генерации псевдослучайных чисел без необходимости переключаться на сторонние утилиты или браузер.

### Основные возможности:
1. **Вызов через палитру команд (Command Palette):** Быстрый запуск рабочего окна по команде `Открыть генератор случайных чисел` (`my-first-extension.openRandomGenerator`).
2. **Настройка диапазона генерации:** Возможность вручную задать нижнюю (`От / Min`) и верхнюю (`До / Max`) границы генерируемого значения (по умолчанию от `1` до `100`).
3. **Валидация входных данных:** Автоматическая проверка корректности введенного интервала — при попытке задать минимальное значение больше максимального (`Min > Max`) плагин выводит предупреждение об ошибке.
4. **Адаптивный интерфейс (Webview UI):** Графическое окно построено на базе VS Code Webview API с использованием нативных CSS-переменных редактора (`--vscode-*`), благодаря чему интерфейс автоматически подстраивается под текущую цветовую тему пользователя (светлую или темную).

* **Пакетный менеджер:** `npm`

### Инструкция по запуску в режиме разработки:
1. Установить зависимости проекта:
   ```bash
   npm install
2. Скомпилировать исходный код:
    ```bash
    npm run compile
3. Нажать клавишу F5 в VS Code для запуска тестового окна [Extension Development Host].

4. В открывшемся окне нажать Ctrl + Shift + P (или F1), ввести команду Открыть генератор случайных чисел и нажать Enter.
